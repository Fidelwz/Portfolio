# Portafolio

Este es mi portafolio personal. Soy Fidel Contreras, desarrollador full stack, y trabajo principalmente con PHP, Laravel, JavaScript y MySQL.

Quería que se sintiera como mi entorno de trabajo en Fedora: oscuro pero sin negro puro, con detalles de terminal y sin efectos de más. Lo armé con Next.js, React y Tailwind CSS.

## Qué tiene

- Una paleta de comandos con `Ctrl + K` para moverse entre secciones, copiar mi correo o abrir mis redes.
- Una terminal en el inicio con tres vistas de mi perfil: `systemctl status`, `fastfetch` y un `stack.yml`.
- Mi experiencia contada como un `git log`, con lo que hice en cada empresa, la arquitectura y las tecnologías que usé.
- Mis repositorios más recientes, cargados en vivo desde la API de GitHub.
- Las tecnologías que manejo agrupadas por área, sin barras de porcentaje.
- Un formulario de contacto con Web3Forms que muestra el resultado del envío como la salida de una consola.

## Stack

Next.js 16, React 19, Tailwind CSS 4 y TypeScript, con pnpm como gestor de paquetes.
